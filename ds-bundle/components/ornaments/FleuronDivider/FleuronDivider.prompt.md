FleuronDivider from @vcpx/design-system. Use via `window.VCPX.FleuronDivider` (bundle loaded from the root `_ds_bundle.js`). Wrap the tree in `<DSProvider>` (full provider chain in README.md — components read theme/i18n from that context).

Séparateur de section : un filet qui s'efface vers les marges, interrompu par un fleuron. Pour séparer deux moments d'une page éditoriale, là où une bordure franche serait trop sèche.
