GoldRule from @vcpx/design-system. Use via `window.VCPX.GoldRule` (bundle loaded from the root `_ds_bundle.js`). Wrap the tree in `<DSProvider>` (full provider chain in README.md — components read theme/i18n from that context).

Filet doré horizontal, en dégradé s'effaçant vers les bords. Plus discret que `FleuronDivider`, sans ponctuation centrale.
